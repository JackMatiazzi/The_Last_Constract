# The Last Contract

Jogo 3D em terceira pessoa feito em Godot 4.7 para a disciplina de Programação de Jogos.

Grupo: André Bartzen Araujo, Jackson Matiazzi e José Maciel Camargo.

## Protótipo

Primeira versão jogável: o Knight anda, corre, pula, empurra caixotes e barris e ataca um esqueleto de treino num mapa de teste.

Controles:

- WASD: mover
- W duas vezes: correr
- Espaço: pular
- Mouse: câmera
- Botão esquerdo: atacar
- Esc: soltar o mouse

Para rodar, abrir a pasta no Godot 4.7 e apertar F5.

## Testes

Usamos o gdUnit4 (em `addons/`). Os testes ficam em `tests/` e rodam pela aba gdUnit do editor
ou automaticamente no GitHub Actions a cada push.
